為了讓應用程式裡的 emoji 在每一台裝置上都看得到、而且畫風一致（不同版本的系統內建的 emoji 長得不一樣，較舊的版本還會缺字、顯示成方框），本應用程式內含 Noto Color Emoji 的字形子集 —— 只含應用程式用到的 emoji，不是完整字型；子集是開發者自己從上游字型擷取的，所以是修改版。請勿把它當成字型安裝或再散布使用；要取得完整字型，請到 https://github.com/googlefonts/noto-emoji。

Bundled font subset and its licence

So that the emoji in the App show up on every device and look the same everywhere (different system versions draw emoji differently, and older versions lack some and show boxes), the App bundles a glyph subset of Noto Color Emoji — only the emoji the App uses, not the complete font. The developer extracted the subset from the upstream font, so it is a modified version. It is not intended to be installed or redistributed as a font; the complete font is available at https://github.com/googlefonts/noto-emoji.
